# Student Grade Calculator 

## About the Project

This is a beginner-friendly Python project that calculates student marks, average percentage, grade, and result status.

## Features

* Enter student name
* Input marks for three subjects
* Calculate average marks
* Automatically assign a grade
* Display pass or needs-improvement status

## Technologies Used

* Python
* Visual Studio Code

## How to Run

1. Install Python.
2. Download `grade_calculator.py`.
3. Open the terminal in the downloaded file's folder.
4. Run the command:

   `python grade_calculator.py`

## Project Purpose

This project helped me practise Python programming, functions, conditional statements, user input, and calculations.
